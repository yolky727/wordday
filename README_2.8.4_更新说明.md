# WORDDAY 2.8.4 · 界面与回看修订

以 2.8.3 为基础的完整覆盖更新包，保留此前的动物对阵和简化技能规则。

## 更新内容

- 战斗界面适度精修：比分栏、牌桌边框、出牌提示、胜负动画采用统一细节，继续保持全屏及 3:4 卡牌比例。
- 结算界面采用独立徽记、清晰的胜负标题、居中比分列及整齐的操作按钮；失败仍显示“失败”。
- 开屏恢复 2.8.2 的 W. 标志、WORDDAY 标题、英文短句与主要布局，微调留白、字号、分隔线和按钮。
- 战斗音效去重：战斗面板不再叠加通用按钮点击声，同一动作按“回合结算 → 技能 → 出牌”选择一种反馈；新的战斗旋律会停止旧旋律，取消尚未解锁的过期播放请求。整场结果在结算页面显示时播放，继续遵循静音、音量和音色设置。
- 进阶卡固定为黑色金属与金色细节，跨森林、午夜、海洋、复古主题保持一致；图鉴、展示、任务获卡和我方战斗牌均复用同一牌面。
- 每日学习的左右箭头在原位置回退、前进整个单词卡，保留词性、释义、例句、发音、收藏与详情。过去词卡显示已记录的学习状态，回看不重复计入学习量。
- 测试左右箭头回到完整原题，包括原题干、全部原选项或拼写输入框、所选答案和正确答案。返回当前题时保留未提交的输入。四种模式均支持，测试结束后也可回看完整试题。回看不修改答案、分数或连击。
- 修正顶部圆形连续打卡数字的水平、垂直居中，标签独立定位；继续使用原有数字字体。

## 覆盖更新

1. 可先在「个人 → 设置 → 数据与备份」导出备份。
2. 解压后将包内文件及 maintenance 文件夹上传到原 GitHub Pages 仓库根目录，覆盖同名文件。
3. 等待部署完成后，联网打开原网址，页面版本应显示 2.8.4。主屏应用若仍显示旧版，关闭后重新联网打开。不要清除网站数据。

继续使用原学习与收藏存储键，保留打卡、收藏、卡牌库存、进阶状态、任务领取记录及历史战绩。2.8.3 的未完成对局可继续。本包不会自动发布到仓库。

## 验证

通过词库与脚本校验、原有战斗规则校验，以及音效互斥/静音测试。Chromium 手机视口验证了从 2.8.3 升级及离线重载、存档保留、全屏与卡牌比例、触屏长按/拖牌、四主题一致的进阶材质、完整词卡回看、四种题型回看、未提交输入保留，以及已完成测试回看不重复保存成绩。真实 iPhone Safari 的音量与系统音频策略仍需实机确认。

- `node maintenance/validate.cjs`
- `node maintenance/battle283.cjs`
