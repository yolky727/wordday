WORDDAY 2.5.2 — GitHub Pages 更新包

升级自 WORDDAY 2.5.1，覆盖仓库根目录同名文件即可。

新增：
1. 「动物卡牌」界面称谓统一为「萌物卡牌」；保留内部存储键避免丢失历史收藏。
2. 在妙想 → 萌物图鉴中，点击已获得卡牌，进入正反面 3D 观察。手指左右拖动可连续绕 Y 轴旋转，纵向拖动轻微俯仰；轻点卡面翻面；有复位按钮。四种稀有度拥有各自对应色系的卡背。
3. 修正部分名称与 Emoji 不符的问题：有准确专属 Emoji 的萌物显示 Emoji，没有准确专属 Emoji 的萌物使用中性图形识别符和英文首字母，避免错误动物图像误导。后续可逐步替换为准确原创插画。
4. 妙想入口与卡牌按钮文案精简、布局微调；更新离线缓存版本。

注意：3D 是卡牌的正反面和角度旋转，不是动物本身的真实 3D 模型。
首次覆盖前请备份；不要清理 Safari 网站数据，以免丢失本地记录。
