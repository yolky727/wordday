# WORDDAY 2.8.3

基于 2.8.2 的完整覆盖更新包。适用于现有 GitHub Pages 网站。

## 本次更新

1. **对阵规则**：取消五类战术循环。优先使用你已确认的 134 条对阵结果，再应用老鼠/大鼠对大象、刺猬对狼、蜜蜂对犀牛的特殊克制。其他组合按体型 35%、攻击手段 30%、防御 20%、食物链 10%、特殊性 5% 的游戏评分判断；差值小于 0.12 为平局。同牌平局。74 种动物全部覆盖，双方互换时结果相反。数值是游戏设定，不是生物学测量或现实斗兽预测。
2. **技能简化**：长按卡牌约 0.46 秒发动。换牌、庇护需再选择目标；可通过「选择技能」按钮直接操作。选牌阶段可以发动，亮牌后也可长按自己的出战牌发动，取消先后手、前轮获胜、特定物种等复杂前置条件。每方整场仅一次，决胜局不重置。提升类技能为失败→平局、平局→胜利，不能将失败直接改成胜利；防护只在失败时生效。已经发动的技能不被后续封技追溯取消。庇护没有剩余目标时仍可保护自身当前回合。
3. **全屏竞技场**：组队完成后铺满应用可用视口，适配安全区。卡牌固定 3:4，与图鉴牌面比例一致。我方沿用图鉴完整牌面，对方显示英文。支持拖动到框内或轻点出牌；自动对手、动画结算、自动下一轮、胜负弹层均保留。Safari 的浏览器地址栏由浏览器管理。
4. **声音反馈**：出牌、技能、回合胜负、整场胜负分别反馈，遵循音效开关、音量、音色设置。获卡、进阶、融合的同步反馈保留。
5. **视觉调整**：开屏采用简洁编辑式排版；进阶卡采用稀有度色内框、菱形暗纹、冠状徽记和克制扫光，牌面不写“进阶”，支持减少动画设置。原有数字字体与排版修复保留。
6. **老用户识别**：已有昵称、头像或学习记录的用户直接跳过首次资料引导；新用户填写后同步到当前资料，生日与自我介绍仍选填。

## 如何更新

1. 可先在「个人 → 设置 → 数据与备份」导出备份。
2. 解压，将包内全部文件和 maintenance 文件夹上传到**原仓库根目录**，覆盖同名文件。不要把 ZIP 本身上传当作网页。
3. 等待 GitHub Pages 部署后，联网打开原网站；页面版本应为 **2.8.3**。主屏应用可关闭后再打开。不要清除网站数据。

本次继续复用原存储键，保留学习、打卡、收藏、卡牌库存、进阶状态、任务领奖记录和历史战绩。为避免一局内切换判定规则，旧版未完成对局将重新组队，不计额外胜负。完整更新包不包含个人存档，也不会主动发布到仓库。
