WORDDAY 3.5 Safari 打开修复补丁

原因：3.5 缓存脚本把首页 URL 参数写错，导致截图中的 FetchEvent.respondWith 错误。

操作：
1. 解压本补丁。
2. 打开 GitHub 的 wordday 仓库，在原 service-worker.js 所在目录上传并覆盖本补丁的同名文件，再提交。
3. 等待 GitHub Actions / Pages 显示部署成功。
4. 关闭主屏 WORDDAY 和 Safari 中这个网站的旧标签，再重新打开 https://yolky727.github.io/wordday/ 。
5. 新缓存安装可能需要一点时间；若首次仍出现原错误，稍后再刷新一次。

无需修改 online-config.js，无需重新部署 Supabase。不要清除网站数据，以免丢失本机学习记录。
本补丁只修改缓存脚本，不更改学习记录、卡牌库存或3.5功能。
