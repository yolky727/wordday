WORDDAY 3.7.4 更新说明

本版基于 3.7.3，集中修复开屏与每日翻牌的进入顺序。

1. 首屏直接为开屏
开屏已写入 HTML 初始结构；进入前通过头部内联样式隐藏主页及其子元素，不再等待脚本创建开屏。
每次重新载入页面均先展示开屏。小号 WORDDAY、主题动效和原本点击入场音效保留。
点击入场只执行一次，减少动态效果设置也适用。

2. 每日翻牌在学习页出现后触发
点击开屏，进入学习页面并完成一帧绘制后，再检查当天翻牌。
沿用当天已翻状态和三次限制，不会重置存档或重复发放奖励。
若还有首次个人资料设置提示，则沿用原有顺序，完成提示后再检查翻牌。

3. 为后续进入流程保留接口
开屏和学习模式进入阶段已经分开，今后可以在两者之间接入模式选择页。
本版不添加 5.0 模式选择、冒险或其他未授权功能。

升级方式
正在使用 3.7.3：优先下载“从3.7.3升级补丁”，解压后按原路径覆盖文件。
其中 entry374.js 为新增必要文件；index.html 与 service-worker.js 必须一起更新。
完整包适合重新部署或较早版本升级。上传文件夹里的内容到原 GitHub Pages 发布目录，勿多套一层目录。
保留网站原有 online-config.js。包内不含真实联机配置；不要删除或替换你已经填好的配置。
升级前可从设置导出备份；正常覆盖不会清除本机学习记录、库存或好友数据。无需重新执行数据库脚本。
发布后等待 GitHub Pages 部署成功，再重新打开页面检查底部版本 3.7.4。

验证
已运行首屏静态结构和进入阶段模拟、重复点击、入场音效调用、减少动态效果、学习页绘制后触发、每日已翻/次数/弹层门禁测试。
已通过现有词库与脚本完整性、双语学习内容一致性、英文技能目标选择、抽卡概率及离线缓存回归检查。
本轮未进行真实 iPhone/iPad Safari 实机测试。

数据与规则
本版不修改学习内容、卡牌 ID、战斗判定、技能规则及抽卡概率。
普通单抽流光 0.7%；每周额外流光挑战出现概率 20%，该挑战完成后领取流光；卡包沿用原有规则。
