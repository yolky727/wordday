# WORDDAY 沃尔德 3.1.1

- 表达入口分为「学习表达」和「检验掌握」。短语卡和句子卡并排，表达测试独立成栏。卡片使用同主题的半透明底、细边框和线描图标。
- 表达测试支持题内收藏和标签选择。「保存并退出」可保留当前题、答案和连击，刷新后可续做。选项和文字加大，新增 A–D 标记和进度条。
- 表达错题本自动收录答错的表达，支持查看原卡和按错题范围组卷。
- 表达接力的主题宝箱换为金色卡包。打开时封条向右撕开，第一张卡向上滑出，随后逐张揭晓。

## 部署

解压后按原目录结构覆盖 GitHub Pages 的发布目录，确保 index.html 仍在原位置。保留原网址和路径，用原设备和浏览器访问原有本地存档。首次联网加载后更新离线缓存，页面底部显示 3.1.1。
