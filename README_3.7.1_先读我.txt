升级方法
1. 先在个人 → 设置导出学习备份。
2. 已安装 3.7：解压「从3.7升级补丁」，将里面的文件上传到原来的网站目录，覆盖同名文件并添加新文件。
3. 使用完整包也一样：保留你网站上自己的 online-config.js；本包不包含真实联机配置，不需要重新运行 SQL。
4. GitHub Pages 发布完成后刷新或关闭旧标签重新打开。底部应显示 3.7.1。
5. 不要清除网站数据。卡牌、学习记录、好友配置、配队与奖励规则保持原有数据结构。
