# WORDDAY 2.9 · 沃尔德

将压缩包解压，把其中的文件上传到原仓库发布目录并覆盖同名文件。部署成功后联网打开原网址，页脚应显示「WORDDAY · 沃尔德 · 2.9」。保留网站数据即可继续使用原有学习记录、收藏、卡牌、对战记录和胜利奖励。

- 「沃尔德」成为 WORDDAY 的化名，也用于对战中的对手。
- 进阶卡沿用基础版式，用更鲜明的同色边框和光晕区分四档稀有度。动物表情会上浮、轻摆并放大。进阶时边框光效展开，再呈现卡面。
- 结算标题上方移除圆形图案。胜利、平局、失败分别呈现金色放射、柔光和冷色淡入。
- 按最终确认的 34 张技能方案调整。水獭亮牌后可把落败改平，并让对方在下一普通回合先出牌。每方整场可用一次技能。虎鲸的双倍计分仅适用于普通回合。
- 成就以独立弹窗展示，能显示在对战界面上方。新增乘胜追击、绝处逢生、四轮全胜和战利收藏家。连胜、救场和全胜从 2.9 开始统计，领取奖励成就会读取已有领取记录。

进阶与结算动效遵循减少动态效果设置。技能详情可在卡牌查看界面和对战技能面板查看。
