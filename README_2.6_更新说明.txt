WORDDAY 2.6 · Swiss Glass 更新包

使用方法：将压缩包内全部文件上传至 GitHub 仓库根目录，覆盖同名文件，提交后等待 GitHub Pages 部署。Safari 如仍显示旧版，可关闭主屏幕网页并重新进入，或在 Safari 中刷新。

基于 2.5.2 继续开发，保留原本学习数据的 localStorage 键。

本次已实现：
- Swiss 风格字体层级、留白、轻量玻璃 UI 润色，保留四主题。
- 萌物工坊改为卡面选择操作；同款三张进阶、同稀有度重复卡跨级融合。
- 测试答题聚焦布局、退出确认与原有进度保存入口。
- 个人栏目新增设置入口，集中交互反馈、主题配色、主题工作室、背景声景与备份。
- 主题工作室滑块触摸操作与数值反馈增强。
- 四主题独立低音量原创合成环境音循环，默认关闭、用户主动开启；测试及朗读时降低至静音。
- 首次使用个人介绍（昵称、头像、生日、自我介绍），可跳过，生日仅保存在本地；个人中心可编辑。
- 学习数据及卡牌数据 JSON 导入/导出。
- 悬浮导航折叠展开轻量动画优化。
- 更新 Service Worker 缓存版本。

注意：
1. 背景音是本版本原创合成的简洁环境声景，不是商业配乐；没有歌词。手机上试听后再自行调整音量。
2. 本版本为可部署更新包，完成 JS 静态语法和 ZIP 完整性检查；当前环境无法执行完整浏览器端到端测试，建议部署后重点检查 iPhone Safari 触控、开屏、卡牌合成、音频避让和备份。
3. 尚未实现完整 120 种原创矢量动物插画；卡面继续沿用现有 2.5.2 素材和占位图。
4. 3.3 好友系统不在 2.6 内。
5. 资料及备份保存在本地，清理 Safari 网站数据可能丢失；请定期导出。
