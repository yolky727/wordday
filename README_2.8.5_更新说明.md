# WORDDAY 2.8.5 · 胜利进度奖励

基于 2.8.4 的完整更新包，新增战斗胜利进度条。

## 使用规则

- 每累计赢得 **3 场完整对局**，获得一次抽卡机会；不要求连胜。普通回合获胜不单独加进度。
- **每日不限次数**，进度跨天保留。失败、平局不增加也不扣除进度。
- 奖励从达成该轮第 3 胜时，对手持有的四张卡中等概率随机抽取一张。奖池会保存，不会因之后对局变化而替换。
- 满条后可在结算页、组队页或「妙想 → 灵宠对战」入口领取。点击后显示完整卡牌，并播放获卡音效；领取声会停止尚未结束的战斗声音。
- 新卡进入图鉴，重复卡直接增加库存，可用于后续进阶或融合。
- 暂不领取也不会丢失奖励。继续战斗仍可累积下一轮；多次满条的抽卡机会会依次保留。存在待领奖励时，主进度条显示已满，并另外显示下一轮进度。
- 从升级到本版后的新胜利开始计数，不追溯旧版本战绩；升级前尚未结束的 2.8.4 对局，升级后获胜也可计入。

## 更新方式

1. 可先在「个人 → 设置 → 数据与备份」导出备份。
2. 解压，将包内文件和 maintenance 文件夹覆盖到原 GitHub Pages 仓库根目录。
3. 等待部署后联网打开原网址，确认页面版本为 **2.8.5**。主屏应用可关闭后重新联网打开；不要清除网站数据。

保留学习记录、打卡、收藏、卡牌库存、进阶状态、任务领奖记录、历史战绩，以及 2.8.4 的完整词卡/原题回看。对阵规则和技能保持不变。本包不包含个人存档，也不会自动发布。
