# WORDDAY 2.7 · 词库完善版

基于 `WORDDAY_2.6.4_图鉴稀有度排序更新包.zip`，不是重新制作的独立网站。

## 本次完成

- 原有 8,100 个词头全部保留，8,100 条中文释义，覆盖率 100%。原词头标识不变。
- 8,015 条有英文释义，6,842 条有音标，7,873 条有词性字段，保留原有 122 条例句。
- 7,859 条可进入日常学习；241 条专名、外语或构词条目保留查询，独立分类，避免混入随机练习。
- 词形变化可查看原形、复数、过去式、过去分词、现在分词、比较级等（以实际收录字段为准）。变化形式附原形中文释义。
- 中英文搜索，精确词优先展示，四级/雅思/六级/基础/拓展分类，点击搜索结果打开完整详情，可发音和收藏。
- 保留 122 条原有核心释义，加入词典多义解释；编辑修正 weeks、states、arms、termed、staples、eyes 等易错条目。
- 选择、拼写不再被“必须有例句”限制；填词只使用含目标单词的真实已有例句，不用套话凑题；混合题按可用内容选择题型。
- 选择题答案每四题均衡随机分配 A/B/C/D，消除固定循环；少于四个候选时不再产生空选项。
- 完整释义在详情展示，选择题使用首行核心释义，改善手机阅读。
- 查询使用词头映射；换批去重使用集合，减少扩大词库后的重复遍历。
- 手机详情弹窗、长释义排版、键盘焦点、Esc 关闭、减少动画偏好优化。
- 2.7 缓存原子更新：整套核心资源缓存成功后才激活；HTML 与脚本使用同一已安装版本；失败保留旧 Service Worker。

## 重要范围说明

“全部完善”在本次交付中具体指 **8,100 个原词头均有中文释义**，不是 8,100 条都已有例句、译文、搭配和完整词源。

词典数据来自 ECDICT 的 CSV，项目标注 MIT 许可，附 `ECDICT-LICENSE.txt`。原有核心释义与少量编辑补充同时保留。来源：https://github.com/skywind3000/ECDICT 。

词条经过自动匹配、完整性校验和部分异常修正，未逐条人工审校；旧词典仍可能含过时译法或较偏僻的义项。未收录的音标、英文释义或例句不伪造。考试归属是词库标签或旧版分类，不等于已核实真题出处。

详细数量、源数据 SHA-256 和编辑补充名单见 `词库完整性报告.json`。

## 上传方法

1. 在现有网站「个人 → 设置 → 导出备份」保存学习数据。
2. 解压更新包，把里面的文件及文件夹整体上传到现有 GitHub 仓库根目录，覆盖同名文件。不要只上传 index.html；必须同时上传 lexicon.js、wordday27.js、wordday27.css 和 service-worker.js 等文件。
3. 保持原来的仓库、域名和路径。更新后仍使用原 Safari 和主屏入口，不清除网站数据。
4. 等 GitHub Pages 部署成功，联网打开网站。自动更新后「个人」页底部版本应显示 `WORDDAY 2.7 · Lexicon Edition`。
5. 如果仍显示旧版本，关闭网页/主屏应用后重新联网打开。首次离线使用前，需要在线完整打开一次，让词库及页面缓存完成。

本包仅交付更新文件，没有替你推送 GitHub 或发布网站。
