WORDDAY 2.2.1 · 修复更新包

本次基于 WORDDAY 2.2 实际代码修改：
1. 修复“换一组”重复：扩大内置词库，优先未展示词、其次未出现在上一组的词；所有已展示词记录在本地，避免换组反复返回同一小批词。
2. 今日进度与当前词组解耦：换组只更换未完成词，已记录的掌握/不熟悉记录不会回退；调整目标保留历史。
3. 严格分离“单词”和“个人”：学习导航只在单词栏目显示；个人拥有收藏、错词本、详细统计、测试历史入口。
4. 成就徽章统一改为 42px 扁平几何徽章，微切角轮廓、纯色、简约线性成就符号。
5. 保留原有本地存储键 wordday_v1，学习记录、收藏、错词本、测试历史继续使用原数据。

发布到 GitHub Pages：
A. 先在旧网站的“个人 → 详细统计与备份”中导出 JSON 学习备份；保存在设备中。
B. 打开 GitHub 仓库 yolky727/wordday 根目录；用本压缩包中的 index.html 与 service-worker.js 覆盖同名文件并 Commit。
C. 等待 GitHub Pages 部署完成，重新打开 https://yolky727.github.io/wordday/ ，必要时关闭并重新打开 Safari 主屏幕应用。
D. 请勿删除 GitHub 仓库的其他文件，亦勿清除 Safari 网站数据。

注意：本包已做静态代码与算法测试，未在你的实际 iPhone Safari 或线上 GitHub Pages 进行端到端验证。内置词汇标签表示建议学习方向，并不宣称经逐条官方真题核验。用户数据仍仅保存在当前浏览器；不同设备不会自动同步。
