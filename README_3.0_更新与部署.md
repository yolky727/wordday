# WORDDAY · 沃尔德 3.0

## 表达

- 底栏进入「表达」，在「短语」「句子」「测试」之间切换。
- 收录 30 个实用场景、270 条短语和 64 个句子，其中 4 句来自四六级或雅思官方样题，打开卡片末尾的出处可核对。考试方向标签用于练习分类。首版以原创情景练习为主，历年真题语料仍需扩充。
- 句子卡展示译文、主干和句型。卡片可跳转到同场景表达，也可进入词条。点收藏后当场选标签，可在素材本修改。测试支持按已学、收藏、错题或全部内容出题，也可筛选官方样题。测试和学习记录可通过原有学习备份入口导出。
- 每日短读和词汇探索为首批内容。接力每日轮换，包含短语、句子和情景回应。完成后可领取三张卡及一个主题宝箱。表达学习计入奇遇活动时间。

## 宝箱与任务

- 主题奖励与宝箱按低稀有度先翻。右下角显示未翻数量。退出后可在当天继续翻，已入库奖励不会重复发放。
- 宝箱保底普通、稀有、史诗各一张。50% 几率获得一张奇珍。每档额外卡达到第一张的概率依次是普通 90%、稀有 80%、史诗 40%、奇珍 10%。每再多一张的累计概率减半，每档额外最多四张。抽中稀有度后，同档卡牌等概率、独立抽取，允许重复。
- 每日进阶挑战出现率 27%，每周挑战出现率 20%。普通任务和挑战条件按周期轮换。旧存档升级当日、当周保留原任务，下一周期切换到轮换规则。新增三组四级表达成就。
- 融合中显示该卡是否已进阶，库存中的基础副本仍可作为融合材料。

## 部署

将压缩包解压，把其中的文件按原目录结构覆盖到现有 GitHub Pages 发布目录。保留现有网址和路径。用原浏览器或主屏网页应用打开，可继续读取该设备原有学习与卡牌存档。建议更新前从个人页导出学习记录备份。

首次联网加载后，离线缓存会更新到 3.0。若仍显示旧版，保持联网关闭页面，再重新打开。页面底部可查看版本号。
