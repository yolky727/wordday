# WORDDAY 3.3

基于 3.2.1 完整更新包增量修改。根目录 index.html 可直接部署到原 GitHub Pages 路径。

## 本次更新

- 鲸 🐋，虎鲸 🫍，原 ID 与稀有度不变。
- 新增传奇：猛犸象 ID136、长颈龙 ID137、霸王龙 ID138（界面编号为 ID+1）。流光的存储等级仍为4，传奇存储等级为5，但显示与侦察排序为流光高于传奇。
- 传奇不加入任何抽卡、卡包、胜利奖励和融合产出池；不允许作为融合材料。每个存档每种仅能领取一次，领取即进阶，可手选出战。
- 霸王龙：集齐3.3中90种非传奇卡（包括流光）；长颈龙：完成10个不同的情境实练，已有记录计入；猛犸象：进阶87种普通至奇珍卡，排除流光和传奇，避免循环条件。
- 霸王龙「暴君降临」亮牌后使本回合最强；「远古号令」首回合选牌阶段强化其余三张，自身削弱；各消耗一次机会。远古号令不会自动打出霸王龙，之后仍可选择出战牌。有猛犸象时可分别发动两种技能，每种每局最多一次。
- 猛犸象「亘古」增加一次技能机会，对方有独角兽时失效；「冰封」在己方上一回合落败且本回合出场时小幅增强自身。长颈龙「冥想」获胜后增强己方下一回合出场牌；主动技能在选牌阶段揭示对方最高稀有度两张卡，同稀有度随机；侦察不自动打出长颈龙，可根据情报继续选牌。
- 小幅战力提升只调整接近的综合属性对位，保留已确认的特殊克制；霸王龙“最强”优先于回合保护、直接判平；双方同时发动最强则平局。对方有独角兽时主动技能仍全部禁用。
- 传奇卡保持原有布局。暗血红动态渐变框、银色质感流动框、较浅蓝色星空与深蓝动态框；统一远古印记卡背。完整版传奇24粒子、进阶流光32粒子；缩略图减少可见粒子，遵循系统减少动态效果设置。
- 短语、句子目标滑条合并进“筛选与搜索”，保留确认保存。
- 修复英文句子中的错误分隔符导致的空白选项；过滤缺失释义，修复旧测试草稿的空白答案。
- 新增可配置好友联机测试版：邮箱注册登录、密码找回、好友码、好友申请/接受/删除/屏蔽、房间邀请、服务器判定、倒计时与恢复房间。默认配置为空，需站点所有者自行建立 Supabase 项目。
- 联机登录令牌不进入学习数据备份；注册账号不会覆盖本机学习收藏。

## 更新顺序

1. 在旧版「个人 → 设置 → 数据与备份」导出完整备份。不要清除 Safari 网站数据。
2. 覆盖原仓库同一路径的前端文件；保留任何你已有的自定义域名 CNAME。
3. 等待 GitHub Pages 发布，在线重新打开应用；确认底部 3.3。旧服务工作线程正在更新时，安全退出一次再重新打开。
4. 单机功能无需配置即可使用。好友联机请用电脑打开本包 `好友系统配置指南.html`，按步骤执行。
5. `backend/03_wordday-online.ts` 是可整份粘贴到 Supabase 的函数源代码。`backend/supabase` 提供同一份代码的 CLI 目录，二选一部署。

## 重要范围

保留原 localStorage 键名、卡牌 ID、库存、进阶与打卡数据。领取传奇会写入唯一领取凭据，其他奖励继续沿用原去重机制。

好友休闲对战不发单机奖励、不修改单机胜场。用户导入收藏不等于服务器认证收藏，不提供排位与交易。

实际 Supabase 项目与两端设备尚未配置验收；不要将联机代码自检视作真实云端服务已上线。iPhone Safari 真机特效与网络仍需用户设备验收。新虎鲸 emoji 的外观与支持情况由系统字体决定。
