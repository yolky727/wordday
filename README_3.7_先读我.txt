WORDDAY 3.7

本次更新
1. 全屏主题开屏：中央仅保留小号 WORDDAY，轻触任意位置进入；森林、海洋、复古、午夜分别使用缓慢的主题动效。
2. 界面玻璃质感：导航、主要面板、弹窗与次级按钮增加透明层次和细腻边缘；阅读与答题区域保持清晰。
3. 浮动胶囊导航：保留单词、表达、妙想、个人四栏与原有收起操作，切换时移动玻璃选中层。
4. 设置 → 语言：简体中文 / English，自动保存。英文模式使用英文界面、英文词义和表达补全题；不翻译用户自己填写的昵称、简介与回答。
5. 尊重系统减少动态效果；英文开屏提示也随语言切换。

从 3.6 更新（推荐补丁包）
1. 在 WORDDAY「个人 → 设置 → 导出备份」先保存一份学习备份。
2. 解压「WORDDAY_3.7_从3.6升级补丁.zip」。将其中网页文件上传到 GitHub 原来的网站目录，覆盖同名文件，并把新文件一起上传。不要把整个解压文件夹当作网站子目录上传。
3. 保留服务器上原有的 online-config.js。本包不包含真实配置，也不需要重新配置好友后端或执行 SQL。
4. 等 GitHub Pages 发布完成后刷新一次，再关闭旧标签重新打开。底部显示 3.7 即已更新。主屏 WebApp 可完全退出后重新打开。
5. 不要清除网站数据或卸载主屏 WebApp来更新，以免丢失本机存档。

完整包
「WORDDAY_3.7_沃尔德_完整更新包.zip」包含前端全部资源、原有后端说明和维护检查脚本。已有网站仍需保留自己的 online-config.js；不应以 example 配置覆盖真实配置。首次部署请另外阅读原有好友系统配置指南。

保留内容
3.6 的全部模式、每模式独立配队、连胜奖励、卡牌 ID、库存与进阶存档、卡面比例和战斗规则均保留。本次没有加入 4.0 世界栏与 5.0 冒险入口。

验证
