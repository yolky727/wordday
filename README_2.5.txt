WORDDAY 2.5 · WILDWORDS 更新包（基于用户提供的 2.4.1 完整修复版）

部署：解压全部文件至 GitHub 仓库根目录，覆盖旧文件；保留文件名及相对路径。提交后等待 GitHub Pages 发布，Safari 主屏幕应用可尝试彻底退出后重新打开。

本包已实现：
- Editorial Glass 风格的开屏排版更新；开屏后每日三次翻牌，可稍后继续，按本机日期记录次数。
- 120 种动物名称与中英对照的收藏目录、四种稀有度固定卡框、翻转/光泽动效。
- 首次获得直接收藏并解锁对应动物头像；重复抽取需拼写正确才入库；拼写错误也消耗翻牌次数。
- 同动物三张基础卡合成进阶版；跨稀有度融合（8 普通→1 稀有、6 稀有→1 史诗、5 史诗→1 奇珍），保留最后一张基础卡，成功融合新动物仍按首次收集规则领取。
- 学习互动时间累计约 2 分钟出现待领取奇遇；小爪印提示；头像选择网格可滚动。
- 单独本地保存卡牌库存与收藏状态；旧 wordday_v1 学习数据不改写；PWA 缓存版本更新。

当前限制（请务必知悉）：
- 120 张卡面当前为统一版式 + 动物 Emoji 占位，尚未绘制 120 张原创矢量动物插画；部分冷门动物共享相似 Emoji，不代表最终美术交付。
- 词库沿用 2.4.1 原有已审核学习词条与英文词头索引，尚未完成全面四级/雅思释义词库扩充；不能将未释义词头视为可学习词条。
- 学习奇遇有效时长采用最近 45 秒有学习交互的时间段，平均约 2 分钟一次；目前小爪印优先展示在今日学习入口，尚未细分所有测试模式按钮。
- 抽卡概率当前临时为普通 65%、稀有 25%、史诗 8%、奇珍 2%，未实现保底机制。融合配方也是暂定数值。
- 进阶卡为 CSS 动态光泽与呼吸效果，不包含独立动画插画资产；仅本机 localStorage 存储，无跨设备同步。
- 旧版本已有的动物 Emoji 头像会按新收藏规则锁定；原有非动物默认头像和上传照片不受限制。

建议正式上线前先在 GitHub Pages 测试站试用并备份原站点与学习记录。本包为可用功能更新/测试版，不宜当作已完成全部 2.5 规划的最终美术及词库成品。
