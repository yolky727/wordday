WORDDAY 沃尔德 3.4

先备份，再覆盖。不要清除浏览器数据，不要重建 Supabase 项目。

一、已使用 3.3.1：电脑上这样更新
1. 原站「个人 → 设置 → 导出备份」。保留这份 JSON。
2. 保留 GitHub 仓库中已经配置好的 online-config.js。
   本包没有 online-config.js，只提供 example，避免空配置覆盖你的连接。
3. 解压本包，将根目录网页文件上传覆盖原 GitHub 仓库相同位置。
   不要在仓库里额外套一层文件夹。backend 与 maintenance 是部署/验证资料。
4. 打开原 Supabase 项目 → SQL Editor → New query。
   用记事本/VS Code 打开 backend/05_upgrade_3.4.sql，复制全文，粘贴并 Run。
   如果尚未升级过 3.3.1，先执行 backend/04_upgrade_3.3.1.sql，再执行 05。
   05 只增加私有实时通知权限、函数和触发器，不删原数据表。
5. Supabase → Edge Functions → 原来的 wordday-online → Code。
   用记事本/VS Code打开 backend/03_wordday-online.ts，复制全文覆盖旧代码 → Deploy。
   保留原来的函数名称和 JWT 配置；CLI 用户可部署 backend/supabase 中的同一份函数。
6. 等 GitHub Pages 发布完成，完全退出后重新打开 Safari/主屏幕 WebApp。
   页脚应显示 3.4。双方都更新后，新建好友房间测试。
   无须重新注册、重加好友、填新公钥或购买服务器。

不要双击 JS 文件运行；JS 用记事本编辑，由网页加载。
首次配置请先读《好友系统配置指南.html》，建好基础表、Auth和函数，再执行 04、05。
任何 service_role/secret 密钥都不能放进 online-config.js 或上传到网页仓库。
