# WORDDAY 3.2.1

基于 3.2 的修正与界面润色。保留原有学习、目标、收藏、错题、实练草稿、卡牌和奖励存档。

1. 情境提示按当前轮配置：21 个情境的 63 轮对话共 128 条针对性搭配。同一情境的请求、进度说明、确认等环节不再复用整组提示；复练与接力同样使用当前轮内容。
2. 表达接力与任务卡包的总览共用新的静态卡面快照。原生 emoji 独立占位、禁止压缩，并移除总览中的动画、位移和滤镜；保留原卡身份、稀有度配色与编号。逐张抽卡及图鉴卡面的动态效果继续保留。小屏幕自动调整列数，可滚动查看全部卡牌。
3. 移除短语卡、句子卡的查词按钮。发音、收藏、关联表达、已掌握/未掌握与自动下一张保留；单词系统本身的查询功能不变。
4. 保留用户认可的情境实练玻璃页头，将相同的圆角、半透明底、描边、留白和信息层级应用到旧版单词学习、单词测试、复习、收藏/错题子页及设置。沿用原四主题配色，不添加装饰渐变，不更改原功能流程。
5. 短语与句子的每日目标改为滑动选择：支持滑条、加减和快捷数量，无需唤起数字键盘。短语最低 7 个，句子最低 3 个，最高仍为 200 个。点「确定目标」保存，两类目标独立记录，原有目标及奖励判定继续使用。

## 部署

先在现有网站导出备份，再把解压后的文件覆盖到原来的 GitHub Pages 目录。不要改变域名/路径或清除网站数据。发布完成后重新打开，确认底部版本为 3.2.1。离线缓存会在新资源完整下载后切换。
