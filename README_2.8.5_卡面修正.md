# WORDDAY 2.8.5 修正版 · 原午夜进阶卡

本次仅纠正进阶卡面，不重新设计。

- 撤销 2.8.4 新增、沿用到 2.8.5 的统一黑金卡面覆盖样式。
- 恢复 2.8.3 的进阶卡原样式：四档稀有度各自的边框颜色、原徽记、原纹理、原渐变与光效。
- 原进阶卡的半透明渐变会透出午夜主题背景。本版仅将这一午夜底色固定到进阶卡自身，让森林、海洋、复古和午夜主题都呈现原午夜卡面效果。
- 普通卡不受影响。2.8.5 的三胜抽卡、累计进度与未领取奖励，以及学习、测试、战斗功能全部保留。

另修正胜利抽卡的随机索引：每次领取只随机一次，避免查找卡牌时反复随机而偶发提示“卡牌不存在”。三胜规则和四张牌奖池不变。

## 更新

解压后，将包内文件和 maintenance 文件夹覆盖到原仓库根目录。部署完成后联网打开原网址，底部应显示「WORDDAY 2.8.5 修正版」。不用清除网站数据，进阶状态、卡牌库存、胜利进度及待领奖励继续保留。

## 验证

与 2.8.3 原午夜主题对比了四个稀有度卡面的边框、阴影、渐变、文字、纹理与徽记计算样式，并检查四种主题切换后一致。原词库、脚本、三胜奖励与声音校验通过。浏览器验证缓存升级、抽卡及存档保留；未进行真实 iPhone Safari 实机测试。
