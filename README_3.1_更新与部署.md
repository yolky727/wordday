# WORDDAY 沃尔德 3.1

- 表达首页设有短语卡、句子卡和表达测试三个独立入口。每日短读独立展示，素材本置底，词汇探索移至单词栏。
- 短语和句子全屏练习，筛选默认折叠。表达测试先打开独立弹窗，显示题目设置、三种模式和分模式战绩，选择模式后全屏答题。答题沿用单词测试的音效和连击动画。旧成绩继续保留，缺少模式记录的成绩不计入分模式战绩。
- 表达接力每三天更新一组，可跨天续做。五道客观题加一道场景回应，回应须至少两句、共十二个英文词。回应按格式检查，提供参考表达供自评。
- 流光卡领奖卡面居中。进阶成功时，龙、凤凰、独角兽分别播放翠绿、红色、粉色边缘光效。
- 非午夜主题的奇珍进阶挑战按钮改为浅金底和深棕字，保留金色流光边框。

## 部署

解压后按原目录结构覆盖 GitHub Pages 的发布目录，确保 index.html 仍在原位置。保留原网址与路径，并在原设备和浏览器打开，以继续使用原有本地存档。首次联网加载后，离线缓存会更新到 3.1。页面底部可查看版本号。
