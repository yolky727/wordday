WORDDAY 2.2.2 · 更新说明

重要：这是词库索引扩充版，不是 8100 条完整中文释义词典。
经验证的中文释义学习词条约 122 条；另外补充 7978 条独立英文词头索引（来源为 TextBlob 英语频率语料，经 CMU 发音词典筛选）。这些词头尚未补全中文释义、例句和考试来源，因此不参与每日学习与测试。不能把 8100 条索引宣传为 8100 条完整可学习词条。

更新文件：index.html、service-worker.js、vocabulary-index.json，必须全部上传至 GitHub 仓库根目录。
新增：可搜索英文词头索引、词库加载失败提示、可拖动/点击折叠底部胶囊导航、四主题测试对比度修复、基于 Web Audio 的音效及设置、轻量交互动画、每次测试最多20题。
保留旧版 wordday_v1 本地记录，上传前请先从旧版导出 JSON 备份。不要清除 Safari 网站数据。
音效在 iOS Safari 中需要用户手势激活；系统减少动态效果设置将关闭动效。
本地预览请打开 wordday_local.html；GitHub 更新需同时上传词库 JSON。
