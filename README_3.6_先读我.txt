WORDDAY 沃尔德 3.6 — 竞技场扩展

从已正常使用的 3.5 升级：
1. 建议先在个人 → 设置导出备份。不要清除网站数据。
2. 解压更新包，将网页文件覆盖上传到 GitHub 原目录；不要再套一层文件夹。
3. 保留仓库中你原有的 online-config.js。本包不包含该已配置文件。
4. 等 Pages 部署成功，关闭旧网页和主屏 WORDDAY，再重新打开；底部版本应为3.6。
5. 本次仅修改本地竞技场和展示，无需重新部署 Supabase，也无需执行 SQL。backend 文件沿用3.5。
   若是直接从3.4或更早升级，请另按3.5的旧说明完成之前缺少的后端升级。

竞技场：
• 保留双列模式选择、下方详情、配队和开始挑战；模式区域可上下滚动，共10种模式。
• 五个段位加入指定描述，原始段位条件与首次奖励保持。
• 镜像对决：双方同一阵容、相同进阶状态，顺序各自决定。五连胜解锁「破镜重圆」和1个卡包。
• 小兽逆袭：双方仅普通和稀有，可选己方已有进阶牌。五连胜解锁「无名小卒？」和1个卡包。
• 藏龙卧虎：双方三张普通加一张流光或传奇，暗牌隐藏身份与稀有度。己方需要已发现三种普通和一种高阶牌；配队最多选三普通一高阶，空位随机。五连胜解锁「逗逗你的」和1个卡包。
• 命运换位：配队后选一张牌，与沃尔德预先选定的一张交换，进阶状态随牌移动；交换仅本局有效，不改收藏库存。五连胜解锁「借过一下」和1个卡包。
• 原有整蛊专家仍三连胜首次奖励，不改为五场。
• 各模式配队、未完成对局、连胜和奖励独立保存，刷新后保留；再战沿用本模式手选阵容，随机空位重新抽取。
• 首次奖励领取后，除无双外所有模式每三连胜获得随机一张卡；无双每五连胜获得1个卡包。不会重置总连胜；失败/最终平局重置当前连胜和循环奖励计数。已攒出的待领奖励不会丢失。
• 循环随机单卡沿用现有常规随机卡概率，包含流光，不包含传奇。首次奖励不重复，循环奖励可继续累积、逐次领取。旧版已领奖励不追溯补发历史循环奖励，从升级后新胜场开始计数。
• 首次七连胜通关无双，播放指定结局全文，解锁「黄粱一梦」「Bless you」，保留原「无双驯兽师」。跳过可直接显示结尾，再点继续退出；之后详情页可重看。已在旧版通关者直接拥有新称号，并可手动重看结局。
• 沿用最新3.5飘带/粒子与Safari修复，龙闪电保持现状。学习记录、卡牌ID、抽卡概率和进阶数据不变。
