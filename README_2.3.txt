WORDDAY 2.3 · Flow & Memory Edition

GitHub Pages 安装：先导出旧版学习数据备份，然后将 index.html、service-worker.js、vocabulary-index.json、manifest.webmanifest、icon-192.png、icon-512.png 上传到仓库根目录，覆盖同名文件。等待 Pages 构建并刷新 Safari。不要删除 Safari 网站数据，否则本地记录可能丢失。

本地预览：打开 WORDDAY_2.3_本地预览.html；本地文件不保证支持所有 Safari PWA 特性，正式使用推荐 GitHub Pages。

说明：本版本保留 wordday_v1 本地数据键，并扩展 wd23 数据。完整释义词条沿用 2.2.2 基础词库，另附英文词头索引；英文索引没有中文释义，不能当成完整四级/雅思词库。未实现跨设备同步。

主要新功能：单词卡专注学习、每日一词、可折叠词库索引、主题音效、测试存档与收藏、连对反馈、32枚成就、40种头像、上传头像、悬浮导航球、开屏。

注意：智能复习算法、全量四级/雅思释义词库、可自由调整的图片裁剪、易混词题库等仍属基础实现或待补充，不能宣称已全部完成。
