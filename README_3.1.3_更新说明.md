# WORDDAY 3.1.3 — 更新说明

基于用户上传的 3.1.2 完整更新包，保留原文件及浏览器 localStorage 存档。

## 本次调整

- 表达接力「三张奖励卡」改为先显示卡包并播放拆封动画，再逐张揭晓；主题卡包原有动画保留。已领取的奖励继续从原有领取记录恢复，不重新发放。
- 短语与句子学习页面「筛选与搜索」下方新增每日目标，可修改并保存，最低分别为 7、3；每日学习记录按单张表达首次记住计数。
- 「任务与奖励」新增每日固定任务：当天完成单词、短语、句子目标，手动领取一个卡包（3 张随机卡牌）。
- 新增每周固定任务：7 天完成单词目标、复习掌握 30 个内容、累计登录 7 天；各可手动领取一个卡包。
- 固定任务置于随机任务之前，原有奇珍/流光进阶任务继续置底。
- 提升 Service Worker 缓存版本到 3.1.3。

## 计数说明

- 每周从周一至周日；登录按本版本开始使用后的真实打开日期记录，不倒填历史登录。
- 复习任务：单词的「到期复习—记住了」以及短语/句子重复复习或从错题中掌握，按当日去重累计；旧版没有的明细记录不会凭空补算。
- 固定任务的「卡包」按 3 张随机灵宠卡发放，领取即加入库存；原有随机任务仍按原来的单卡奖励规则。
- 已存在的单词学习目标和历史学习数据不迁移或重置。旧版缺少的短语、句子逐日学习明细无法准确回填。

## 安装

先在个人中心导出备份；将 ZIP 中全部文件覆盖上传到 GitHub Pages 仓库根目录，保留文件层级。刷新 Safari 页面；如仍显示旧版，关闭主屏 Web App 后重新打开并等待缓存更新。
