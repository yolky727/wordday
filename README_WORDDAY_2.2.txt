WORDDAY 2.2 · 主题与成就版（首轮体验包）

本包基于 WORDDAY 2.1.2 GitHub 更新包制作，保留原有测试、词卡、复习、收藏、错词本和数据导入导出。

本轮升级内容
1. 新增底部双主导航：单词 / 个人；原有学习、测试、复习、收藏、错词本入口保留在单词主区域。
2. 新增动态主题：森林、海洋、复古、午夜。主题选择保存在当前设备。
3. 新增个人中心：昵称与预设头像、学习统计、年度学习热力图、成就徽章展示。
4. 新增扁平化多边形成就徽章：铜级棕色倒三角、银级灰色菱形、金级黄色五边形、钻石级蓝紫色六边形；中心图案对应成就。徽章按真实学习数据解锁。
5. 优化“换一组”：优先抽取未完成、未展示过的词；切换批次不清除当天已完成记录；今日进度按当天实际完成数与目标数统计。
6. 选择题正确答案位置按 A/B/C/D 轮转平衡，减少正确答案总在同一位置的情况。
7. Service Worker 缓存版本升级为 wordday-v2.2-theme-achievement。

重要说明
- 保留 localStorage 键 wordday_v1，不主动清除旧学习数据。
- 个人资料、主题、展示历史和学习记录均保存在当前浏览器，不会自动跨设备同步。
- 年度热力图只根据现有 studyLog / daily 学习记录绘制；旧记录没有具体学习数量时，不会伪造更细的数据。
- 当前内置词库仍沿用 2.1.2 的基础词库规模。本轮没有为了增加数量而批量编造词条、词源或真题出处；高质量词库扩充应单独经过数据核验。
- 学习伙伴不在 2.2；词汇探索地图、短语专项、句子专项仍留待 3.0。
- 成就徽章当前为首轮条件与图形实现，后续可继续调整等级阈值、成就类型和图案细节。
- 头像暂提供内置选项；本轮尚未加入本地照片裁剪上传。

GitHub Pages 更新步骤
1. 先打开现有 WORDDAY，在原版本中导出 JSON 学习记录备份。
2. 解压 WORDDAY_2.2_GitHub更新包.zip。
3. 进入仓库 yolky727/wordday 根目录。
4. 上传并覆盖 index.html 与 service-worker.js 两个文件，不要删除仓库中的其他资源。
5. Commit changes，等待 GitHub Pages 部署完成。
6. 使用原网址 https://yolky727.github.io/wordday/ 打开验证；再关闭并重新打开 Safari 主屏幕应用。
7. 不要通过清除 Safari 网站数据来强制更新，以免丢失本地记录。

验证范围
已进行内嵌 JavaScript 语法检查、Service Worker 语法检查及关键代码静态检查。尚未在用户的真实 GitHub Pages、iPhone Safari 和主屏幕 PWA 环境完成端到端验收。建议先导出备份，再在测试环境试用。
