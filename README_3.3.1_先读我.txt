【从 3.3 更新：需要更新网页 + Supabase 后端】
先在原站“个人 → 设置 → 完整备份”导出存档。不需要清除浏览器数据。

1. 保留你目前已经填好项目地址和公钥的 online-config.js，别覆盖、别删除它。
   本更新包只提供 online-config.example.js，防止空配置覆盖你现有的连接。
2. 电脑解压更新包，把根目录网页文件上传覆盖原 GitHub 仓库相同位置。
   backend 是服务器配置文件；maintenance 是校验脚本，不需要作为网页运行。
3. 登录原 Supabase 项目 → SQL Editor → New query。
   用记事本/VS Code 打开 backend/04_upgrade_3.3.1.sql，复制全文 → Run。
   这是增加好友档案和赠牌表的迁移，不要删除旧表，不要重建项目。
4. Supabase → Edge Functions → 你原来的 wordday-online 函数 → Code。
   用记事本/VS Code 打开 backend/03_wordday-online.ts，复制全部内容覆盖旧函数 → Deploy。
   函数名、项目地址、公钥不变。不要把服务端 service_role 密钥填到网页。
   CLI 用户也可使用 backend/supabase/functions/wordday-online/index.ts 和原配置部署。
5. 等 GitHub Pages 发布完成，完全关闭再打开网页/主屏幕 WebApp。
   “个人”页底部显示 3.3.1。双方都升级后再新开好友对局；旧对局可先认输结束。

【赠牌使用】
打开好友系统 → 点击好友昵称 → 选择可送卡牌 → 确认发送。
自己的“我的档案与礼物”中查看收到的卡并领取。
每个发送者每天对每位好友最多赠送1张，可以送给多位好友；按北京时间零点刷新。
仅能送多余基础卡：未进阶的卡至少留1张，已经进阶的卡可以送出剩余基础卡，进阶资格不变。
流光可赠，传奇不能赠。发送后不能撤回，收件人主动领取。
网络结果不明确时，卡会暂存于本机待确认记录；点“重试确认”复用原编号，不会再次扣卡。
每日次数由数据库唯一约束控制，发送与登记在同一事务完成。
领取回执绑定首次领取设备，同一设备重试不重复加卡；另一设备请迁移原设备“完整备份”，不要重复领取。
赠牌记录同账号可见；不要在有待确认赠牌时清除浏览器数据或切换旧备份。
现有卡牌来源仍为本地存档，赠牌适合好友休闲收藏，不代表已建立服务端防作弊库存。
