解压后将文件和文件夹整体覆盖到原 GitHub Pages 仓库根目录。上传前可在「个人 → 设置」导出备份。保持原有网址与浏览器，联网打开，页底显示 WORDDAY 2.8 后即可使用新版。保留网站数据。

## 从哪里开始

- **妙想 → 萌物对战**。已发现至少四种启用的萌物即可开战，同种重复库存计为一种。可指定零至四张已进阶牌，余位从已发现的不同卡牌中随机补齐。系统从全部 74 种中随机取四种。战斗不扣库存。
- **妙想 → 任务与奖励**。两项每日任务、七项每周任务，每项每周期可抽一张卡，重复卡加入库存。每日按本地日期、每周按周一更新。任务依据实际学习记录、测试成绩和已结算的对战计数。
- **个人 → 成就徽章**。新增十二枚收藏、进阶及战斗徽章。已有收藏可直接满足对应条件。图鉴详情可查看对应动物的战斗技能。
- **今日学习**。首次打开词卡提示左滑「还需复习」、右滑「已掌握」。词卡回看使用今日完成记录，测试回看使用本场已提交答案。右箭头可以逐步返回当前进度。回看仅供阅读，不改动分数或掌握记录。

## 对战与技能

前四轮轮换先后手，每张牌出战一次。每次出牌或亮牌反应限时 20 秒。四轮胜场相同进入决胜局，双方从原四张牌同时秘密选牌。决胜局仍平，整场记平局。退出对战窗口可继续原对局，过期选择按超时处理。

**双方各有一次整场技能机会。** 点击「选择技能」可查看全部手牌技能、条件及目标。只有确认发动才消耗机会。按钮随后显示「技能已使用」及对应回合。加赛也使用同一份次数。盖牌在先手选择阶段处理，豁免和改判在亮牌后处理。先后手限定技能在决胜局休眠。

基础胜负使用显式的代表性捕食关系表。图鉴使用宽泛动物名，少数边有物种、种群或幼体条件，已在相关亮牌回合提供提示。例如豹对大熊猫的关系对应幼体。未收录直接关系按平局处理。随机组队容易打平，自动对战测试中约八成整局为平局。手选进阶阵容和保留技能会影响实战结果。

## 画面与声音

进阶卡增加双层边框、菱形星点、旋转轨道和正反面光泽。进阶完成时轮廓扩散，同时播放四音上行动机。融合时卡片轮廓向中心汇聚，配有不同的短旋律。获得卡牌时播放两音提示，适用于翻牌、奇遇、融合奖励、拼写成功领取及任务奖励。音效遵循主题、总开关和音量，支持减少动画。

学习概览原有四项统计使用相同字号，但 Georgia 的数字字形高低不同。2.8 统一为等高等宽数字。已打卡日期的底色、强调线和今天的描边均取当前主题配色。
