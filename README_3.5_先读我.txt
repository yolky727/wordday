WORDDAY 沃尔德 3.5

更新方法（从 3.4 升级）
1. 个人 → 设置 → 导出备份。不要清除 Safari 网站数据。
2. 保留 GitHub 仓库里现有的 online-config.js。本包不提供已配置文件，避免覆盖连接信息。
3. Supabase → Edge Functions → 原来的 wordday-online → Code：
   用记事本或 VS Code 打开 backend/03_wordday-online.ts，复制全文覆盖原函数，再点 Deploy。
   本次凤凰与特殊克制修改了共用战斗规则；只上传前端，好友对战不会使用新规则。
   从已完成 3.4 配置的项目升级，无需新建表、无需执行新 SQL。
   如果仍在 3.3/3.3.1，按旧 README_3.4_先读我.txt 执行缺少的迁移（04、05），再部署本包的最新函数。
4. 把解压后的网页文件覆盖 GitHub 仓库原位置，index.html 与 service-worker.js 必须一起上传。
   不要把整个更新包再套进一个新目录。backend/maintenance 为服务端部署与验证资料。
5. GitHub Pages 部署完成后，关闭旧网页和主屏 WORDDAY，再重新打开。底部应显示 3.5。
   如仍为旧版：先确认 GitHub Actions / Pages 已部署完成，再关闭所有同站标签和主屏应用。
   不要用清除网站数据的方式更新，以免删除本机学习记录。

本次更新
• 卡牌中文开关：个人 → 设置 → 显示卡牌中文。默认开启，关闭后卡牌名称在图鉴、详情、抽取、配队、赠牌与己方战斗等位置统一隐藏或显示英文名称；不改变词汇与表达题库的中文释义。
• 所有战斗中，对方已揭示卡牌只显示英文身份，不显示动物 emoji 和中文；暗牌仍保密。
• 每日三张恢复 3:4；资料编辑生日输入框与表单对齐。
• 三张进阶流光卡使用各自粒子：翠电、余烬、月晕星尘。原版边框保留，独角兽保留原本两条飘带。
• 战斗中保留动态粒子，减少数量及叠加滤镜；不把全部卡面特效暂停。猛犸象雪花不改。
• 灵宠对战、竞技场和好友对战统一结算布局，集中比分、进度和操作；记录默认折叠。
• 好友结算可创建新房间邀请再战，对方接受后正常准备开战。
• 收礼用个人/好友入口红点提示，礼物入口显示数量并直达领取区。在线前台定期检查；不依赖推送权限，不承诺后台实时通知。
• 凤凰「余烬」首次落败使对方本回合少得1分，最低0；不再自动回手。
• 凤凰「不灭」让涅槃每局独立使用一次，不消耗公共技能次数，净辉无法封锁。复原一张已出战牌后仍需正常出牌，不增加回合。
• 五组特殊克制自动生效，优先于进阶和本回合最强；图鉴用线索暗示，不提供对策关系清单。身份变化后按当前身份判定；阵容型压制持续整局。
• 进阶加成进入竞技场共用判定：同名进阶优先；相近的综合属性对位计入小幅优势，明确克制优先。
• 离线更新不再因可选联机配置文件缺失而整批失败；弹窗或对局打开时延后自动刷新。
