# WORDDAY 3.2 · 把表达用起来

基于 3.1.11 完整更新。沿用原有存档键，不重置单词、打卡、收藏、错题、卡牌库存、进阶和任务奖励记录。

## 这次学习流程变了什么

表达首页新增「情境实练」，作为主动输出入口。短语卡、句子卡是素材，识别测试用于辨析，实练负责把素材变成能完成沟通任务的话。

- 21 个原创具体场景，覆盖大学生活、学术讨论、职场沟通、社会议题、日常口语；共 84 个主动表达任务、84 段不同参考回应、63 组搭配提示。
- 每个情境：理解沟通目标 → 三轮回应与追问 → 改变条件迁移。包含礼貌请求、拒绝与协商、澄清、汇报、证据边界等真实沟通功能。
- 支架练习与独立挑战。先自己说或写，再按任务信息自检、查看参考、修改表达。
- 支持录音、停止、回听、单独保存音频、删除，最长每段 90 秒。拒绝授权或设备不支持时，仍可文字练习。录音仅保存在当前浏览器的 IndexedDB，不上传。
- 草稿自动保存，可保存退出，刷新后继续。修改已对照的回应后需重新对照，防止沿用旧检查结果。
- 「我的表达」保留完成记录、初稿与改稿、改进笔记、录音；支持重点标记与复制文字。
- 间隔复练按 1 / 3 / 7 / 14 / 30 天安排。到期后独立完成自检且未打开搭配/参考，才增加间隔；当天重复做不刷间隔等级。
- 四级「开口实练」「独立复练」成就。实练单独统计，不把输出任务冒充短语/句子卡学习量。
- 新建的三日表达接力采用多轮实练；完成后领取原有三张卡与主题卡包，沿用原有防重复发放逻辑。已完成和进行中的旧接力保留原流程与奖励状态。

## 原有页面同步改善

- 短语卡、句子卡增加主动回想区：先看中文任务并回想/输入，再揭晓参考、查词、发音、收藏和记录掌握状态。支持自动下一张。
- 修复切换筛选后继续混入旧范围卡片；修复关联表达/素材本选中内容未正确展示。
- 测试优先使用同场景干扰项，保留短语、句子、综合测试，以及收藏、保存退出、连击、结算和错题本。
- 重整学习、测试、素材本、错题、实练和结算页面的留白、字号、按钮、边框与玻璃页头；兼容原有四种主题，无新增装饰渐变。
- 学习活动仍计入原有卡牌奇遇时间，录音时也计入；后台/离开表达页停止录音。
- 底部版本及离线缓存同步更新为 3.2。

## 建议怎么用

先挑一件近期真会遇到的事，做一组实练；把一句没说清的话改好，过几天不看参考再练。短语/句子卡用于补充缺少的素材，选择题用于辨析，而不是靠一直点正确选项来代替开口。

这是离线可用的预设情境训练，不是在线 AI 对话；不会理解任意回答后临时生成下一句。信息线索检查只是提示，正确性、语法和发音仍需你回听/对照自检，不提供虚假的自动评分。实练数量与自评进度不代表考试等级，也不能承诺多少天达到流利。

## 部署

1. 部署前在当前网站「个人 → 设置 → 数据与备份」导出一次备份。
2. 解压后将包内网站文件覆盖上传到现有 GitHub Pages 目录；不要改变网站域名/路径或清除浏览器数据。
3. 等 GitHub Pages 发布成功后重新打开网站，检查底部为 3.2。新的 Service Worker 会先缓存完整资源，再切换版本。
4. 若仍显示旧版，关闭该网站的所有 Safari/主屏窗口后重新打开，让旧页面释放。不要通过清除网站数据来升级。

录音需要 HTTPS 与麦克风权限。学习备份包含文字实练记录，但**不包含录音文件**；清除网站数据、换设备或浏览器回收存储后录音可能不可恢复。重要录音可点击「保存录音」或「保存这段录音」单独另存。
