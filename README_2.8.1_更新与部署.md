# WORDDAY 2.8.1

先在旧版「个人 → 设置」导出备份，再将解压后的文件和文件夹整体覆盖到原 GitHub Pages 仓库根目录。联网打开原网址，页底显示「WORDDAY 2.8.1 · 萌物竞技场」即可。保留原有网站数据。已经开始的 2.8 对局保留已结算回合，后续回合使用新规则。

## 妙想

「任务与奖励」有独立栏目。每日两项、每周七项，各项每周期可领取一次。集齐 4 种不同萌物后，在「萌物对战」可以选择进阶队员或随机组队。

## 出牌

将英文手牌拖入出牌区，松手即出牌。也可以直接点选卡牌。拖到区域外松手会取消。系统自动应战，双方亮牌，回合胜负动画结束后自动进入下一回合。整局结束弹出胜、负或平局结算。

双方各有一次整场技能机会，含加赛。选择、查看和取消不消耗机会。亮牌后有可用技能时会短暂停留，打开「选择技能」可以在本次操作剩余时限内确认发动。结算和回合切换自动完成。

## 胜负判定

1. 游戏特性优先。Mouse 或 Rat 的「钻隙」克制 Elephant，Hedgehog 的「棘阵」克制 Wolf，Bee 的「蜂扰」克制 Rhino。
2. 其次查看已收录的捕食关系。双方没有直接关系时，使用牌面标明的战术类型。
3. 战术顺序为 Rush、Feint、Ambush、Guard、Reach，循环排列。每种克制后面两种，被前面两种克制。同型打平。战术与特殊克制属于游戏设定。
4. 可用技能在最终结算前发动，平局保护优先。原技能描述中的基础平局，指双方没有直接关系或特殊克制，可在战术胜负生效前改判。第四回合后胜场相同则加赛，再平则整局平局。

在 2,701 对不同卡牌组合中，2,205 对在技能介入前即可分出胜负。同一测试种子各模拟 4,000 场随机阵容自动对战，2.8 平局 3,099 场，2.8.1 平局 222 场。玩家手选阵容后的实战比例会有所不同。

## 操作与视觉修复

- 导航球使用当前位置作为展开动画起点，支持拖动后展开及减少动画设置。
- 进阶、融合改为工坊内确认。确认成功时启动动画与短音，离开成功页不补播成功音效。静音和音量设置继续生效。
- 学习概览和个人统计共同采用原有 Georgia 衬线字形，对齐数字的可见上下边界，并统一数字占位。修正成就入口将总数显示为 32 的旧文案，与实际 44 枚成就一致。
- 保留 8,100 个词头、原有萌物编号、学习存档、任务收据及收藏进阶记录。

已验证 Chromium 中的 2.8 原址升级、拖牌、自动结算、工坊音画、存档和离线重载。真实 iPhone Safari 的音频输出与主屏入口仍需实机确认。
