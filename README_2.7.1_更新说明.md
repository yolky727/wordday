# WORDDAY 2.7.1

## 每日学习

打开「学习设置」，可以输入 1 至 100 的整数，使用加减按钮，或选择 8、15、30、50 词。输入时会显示已学数量和预计剩余数量。点击「保存学习目标」后，设置自动收起，页面带你回到待学预览。「学习范围」在选择后立即生效。

举例来说，今天学完 10 词，把目标设为 15，会保留完成记录并显示 5 个待学词。预览最多展示 5 个词，可以直接点开释义。点击「继续学习」进入词卡。完成后可以返回首页，或在每日 100 词的上限内继续追加。

## 界面与音效

- 首页先展示学习计划、进度、待学词和学习入口。桌面采用双栏，手机采用单栏。
- 词卡的发音、收藏和释义在同一行，学习判断按钮单独排列。一张卡完成后按待学队列顺序进入下一张。
- 午夜主题的连击声采用 G–B–D–G 四音上行，复用午夜交互音色。原有连击节点及静音设置继续生效。

## 更新到现有网站

1. 在旧版「个人 → 设置」导出备份。
2. 解压压缩包，将包内文件和文件夹上传到现有 GitHub Pages 仓库根目录，覆盖同名文件。
3. 在原网址联网打开，查看页面底部的 `WORDDAY 2.7.1`。主屏应用仍显示旧界面时，关闭并重新联网打开。请保留网站数据。
