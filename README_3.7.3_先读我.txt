WORDDAY 3.7.3

修复英文界面无法选择技能
原来的技能筛选依赖界面文字，翻译发生前后文字不同，会把目标列表全部隐藏。
本版改用稳定的卡位编号筛选，不再依赖中文或英文名称。覆盖灵宠对战与竞技场共用的技能界面；好友对战本来就使用选项编号，未修改后端。
已检查翻译前、翻译后以及中英文环境；在浏览器的实际面板代码验证页中，霸王龙远古号令、独角兽指定目标均可发动。

任务概率核查（没有修改概率）
• 普通每日/每周任务单抽：流光合计 0.7%，三种流光等概率。指定抽到独角兽约 0.2333%。
• 每周流光挑战：约 20% 概率在该周生成这个额外任务；完成并领取后必得一张流光。
• 每日奇珍挑战：约 27% 概率出现，奖励奇珍，不是流光保底。
• 任务卡包：每包 3% 概率包含一张流光，不能将这个数作为普通单抽概率。
• 传奇不进抽卡池。
本版将周流光奖励任务明确标为「流光挑战」，避免与普通任务混淆。任务 ID 与已领取记录保持不变。
仅凭获卡截图无法确认领取的是哪种任务，需要结合领取前的任务名称。
